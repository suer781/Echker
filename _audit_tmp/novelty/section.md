# 模型「厌恶烦躁重复」说法与可测机制的距离（审查章节草稿）

> 本轮为只读设计边界审查：未修改 `life_agent/`、`tests/`、`validation_runs/`、`state_dataset_smoke/`，未训练模型。下文新增机制均标注「尚未实现/设计建议」；实测数字来自 `_audit_tmp/novelty/probe_results.json` 的纯 Python 回放，不代表真实训练动力学。

## ① 情绪宣称 vs 可测机制的界线

「像人一样厌恶烦躁重复」是情绪化类比，代码中不存在情绪、动机或饱食度字段。当前可观测机制只有三类：字节指纹精确去重、单帧分布离散度的结构乘权、高损失离群值抑制。三者都不回答「同一内容重复出现时边际改善是否趋零」。把重复降权包装成情绪或习惯化属于口径错误；习惯化若成立，必须落成可记录、可对照、可回归的指标。

## ② 现有清洗器覆盖度与反例（已实测）

`structural_quality`（memory.py:60-79）只在单条序列内部统计字节熵、最长游程、unique 占比；`digest`（27-31）是 ids+labels 的 SHA256，去重只认完全相同的字节序列。实测：静音 PCM 与纯色灰均为 0.001 地板；随机 167 取值（7.19 bits）为 1.0；单调 0..255 完全可预测却也是 1.0；16 周期 0.78125；两值交替 0.0977；长度 8 短序列因 n<16 放行得 1.0。

反例：同一 4 值内容重复到 32/64/128 长度，质量为 1.0/0.78125/0.390625，仅长度不同因子就漂移；同一内块换前后缀后 digest 不同、质量均 1.0；每帧微差的周期流 digest 全唯一，8 帧使干净压力累计到 1.117；抖动表格质量 1.0。债务侧同 digest 叠加权重并 cap 4.0（197-198），`due()` 按原始权重降序偿还（207）：重复三次的零债务（0.5273/0.001）排在新债务（0.1758/1.0）之前，方向与「重复应缓学」相反。

## ④ 硬拒绝的误伤与分布偏置（设计建议）

现状无硬拒绝：`add()` 始终入库，权重地板 0.001，注释明示纯色、静音、稀疏格式不得硬拒。若未来对低新颖度信号直接丢弃或停止学习：静音、纯色、表格、重复日志、协议帧头等合法低熵数据会被永久排除。在 `debt_capacity=512`、`replay_capacity=1024` 下，被拒样本永久缺席 → 干净压力少计、切换更难触发；清洗器 loss 均值/方差 EWMA 只在入库样本上更新，选择偏置把 2.5σ 阈值带偏。**建议边界（尚未实现）**：信号只允许降采样/降巩固优先级、触发探索或作为附加门控；不允许丢弃样本或停止学习。

## ⑤ 与当前「数据挤压驱动」切换的关系：不可混称

当前判据（switching.py:81-87）：`pressure_growth >= repayment_capacity` 且 `passive_delta>0`、`active_delta>=passive_delta`。压力回答「积压待学干净数据是否超过被动侧一次可消化量」；习惯化回答「当前流边际改善是否趋零」，二者正交。纯 Python 回放（合成步数，非真实动力学）：全 0 重复流 12 轮切换 3 次、间隔 [1,2,5]，随机流切换 4 次、间隔 [1,2,3,4]；重复流下容量 EWMA 随压力收缩、阈值自校准到近零仍切换，说明现有机制不以「无聊」为驱动。若用新颖度**替换**压力项：高熵噪声流因新颖度高即触发切换，丢失已学量与偿还能力证据，造成振荡式频繁切换。**建议（尚未实现）**：新颖度只做附加门控或探索触发器，决策记录同时输出压力、容量、步数差与新颖度以便归因。

## ⑥ 分阶段落地建议（均为尚未实现/设计建议）

- **阶段一 只记录**：记录帧内/滚动熵、n-gram 新颖度、复访边际 loss 差，与 LR、步数、结构事件并列落盘。判据：同种子两次运行序列一致，额外 CPU 开销不阻塞在线推理。
- **阶段二 仅降权**：验证后用边际改善/新颖度调整回放抽签与巩固优先级，样本仍入库。判据：低熵合法类入库率不下降，权重变化与边际改善相关而非与帧内熵单因子相关。
- **阶段三 附加门控**：在现有压力 AND 工作量判据之外接低收益门控或探索请求，不替换压力项。判据：高熵噪声流不触发额外切换；重复流边际趋零时出现探索倾向。

## ⑦ 最小实验与回归测试

对照实验：同一初始权重、同一 token 预算、固定种子 7，A 高重复流（固定块+微差周期）、B 高新颖流（固定种子随机/异质帧）。测量：采样权重分布、切换次数/间隔与 reason、每字节边际 loss 改善曲线、`clean_pressure` 与 `repayment_capacity` 走势、TTT 权重位移与探针集 loss 前后差。排除假象：同步记录 LR 轨迹与结构扩张/裁剪；边际趋零须在 LR 未下调、隐藏维度未变、整体 loss 基线未下移时成立。

建议回归测试（种子 7）：① `test_repeated_digest_accumulates_not_familiarity`：重复 5 次 replay unique=1、debt 权重按叠加增长，无独立熟悉度字段更新；② `test_structural_quality_length_context_baseline`：锁定 32/64/128 长度质量基线与短序列放行；③ `test_low_entropy_legal_frames_not_hard_rejected`：静音/纯色/表格/日志全部入库且权重 ≥0.001；④ `test_novelty_is_additional_gating_not_pressure_replacement`：高熵零收益流压力未达容量时附加门控不切换；⑤ `test_marginal_delta_uses_existing_ewma_no_extra_backward`：边际差来自已有 EWMA 前后差，不增加前后向调用。
