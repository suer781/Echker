## 0. 一句话结论

1. **账本估计方差（未知数 a）**：30720 token 位置/周期下，**激活范数 EMA 可用**（单周期估计噪声中位 ≈2–4%，p90 ≈13%，秩稳定 Spearman ≥0.81）；**Taylor 重要性必须用 |g×x| 口径**——符号口径是纯噪声（半侧均值符号相反的通道过半，相对波动触顶 200%），|g×x| 口径噪声中位 9.5% 但**跨周期漂移 ~35% 主导**（梯度量级系统性衰减）；**有效秩极稳**（切分噪声 0.1–0.6%，跨周期 0.9–4.6% 全部是真实漂移）；**ReDo 的 0.01–0.03 阈值不能搬**（32 个 site 全部 0 通道命中），休眠须改层内分位法并跨周期确认。
2. **探测集噪声底（未知数 b）**：242 块全卷的 bootstrap SE = **0.00356 NLL（均值的 0.062%）**；生产配对门控的 **SE = std(d)/√n 实测 0.00216–0.00281（中位 0.00238，均值的 0.038–0.049%）**。门控判决带 ε=2·SE ≈ 均值的 0.084%。对手术容差候选 δ=1%/2%：**SE ≈ δ/24 ～ δ/48，远小于 δ/3**——门控不在噪声里抛硬币，242 块样本量绰绰有余，无需加大探测集。
3. 附带发现（对 M4 设计有直接影响）：同一数据、同一出生权重，仅窗口采样种子不同，单周期真实改善（margin）就在 0.050–0.096 NLL 之间波动（2 倍差距）——**门控判"是否变好"可靠，但单周期 margin 不能当作"学了多少"的精确度量**；M4 的生长收益评估必须跨周期平均。

## 2. 实验 1：账本估计方差

**做法**：连续训练 240 步（=两个 120 步周期），hook 逐步采集每通道激活 L1 范数、Taylor 项（梯度×激活）、每层残差流奇异值（每步 svdvals + 两个 120 步 Gram，Gram 即堆叠 30720×768 矩阵的精确奇异值平方，每步去均值）。离线做**每周期内 5 次随机 60/60 对半切分（两周期共 10 份对照）**+ 1 份 120/120 跨周期切分，R 次切分下重复计算两半估计量。

### 2.1 通道重要性（激活 EMA / Taylor EMA）——相对波动 = |两半之差| / 两半均值

聚合全部 43008 通道（10 份切分合并；h=半周期内 EMA 半衰期，单位=步）：

| 指标 | h=∞（60 步均值） | h=60 | h=30 | h=15 |
|---|---|---|---|---|
| 激活 L1 范数 中位 / p90 | **4.4% / 13.0%** | 4.5% / 13.2% | 4.7% / 13.8% | 5.4% / 16.0% |
| Taylor \|g×x\| 中位 / p90 | **9.5% / 24.6%** | 9.7% / 25.2% | 10.2% / 26.5% | 11.6% / 30.2% |
| Taylor 符号 g×x（取\|半侧均值\|） | **200% / 200%（触顶）** | 200% | 200% | 200% |

（注：聚合值掩盖 site 差异——120/120 跨周期下 ln1_out 类 site 波动最小、attn_out 类最大，见 §2.1 末条与 exp1_results.json 逐层数据。）

- **符号口径判死刑**：相对波动的理论上限是 200%（两半反号），中位数恰为 200% → **过半通道的两个半侧均值符号相反**。梯度×激活的符号在 token 间随机抵消，单周期 EMA 的符号分量是纯噪声。账本只能用 |g×x|。
- **120/120 跨周期**（含真实漂移）逐 site：激活 med 4.4–11.1%（p90 10–28%；离群稳层 b0.ln1_out 仅 0.4%/1.0%），Spearman **0.81–0.99**；Taylor |g×x| med 13.9–41.9%（除 b0.ln1_out 外 26.6–41.9%；p90 31–65%），Spearman 0.57–0.94。
- **噪声 vs 漂移分解**：每步趋势（240 步 Spearman 中位）激活 **+0.04**（无系统趋势）、Taylor **−0.27**（系统性衰减）；滞后一阶自相关 0.12 / 0.17（近独立）。由 60/60（4.4%）与 120/120（~7–8%）反推：激活的单 120 步估计噪声 ≈ **2.2%**，跨周期漂移 ≈ **7%**；Taylor 噪声 ≈ 6.7%，**漂移 ≈ 34% 主导**（训练推进 → 梯度量级整体衰减，是真实信号而非采样误差）。
- 秩稳定性：半侧 Spearman 聚合中位 激活 **0.958**、Taylor |g×x| **0.898**——"哪些通道重要"的排序比数值稳得多。

### 2.2 有效秩（RankMe 式奇异值熵，每层残差流）

| 层 | Gram-ER 周期1 | 周期2 | 跨周期相对差 | 60/60 切分中位 |
|---|---|---|---|---|
| b0 | 566.1 | 560.8 | 0.9% | 0.1% |
| b1–b6 | 557.8→508.9 | 547.4→487.5 | 1.9%→4.3% | 0.1–0.6% |
| b7 | 503.0 | 480.4 | 4.6% | 0.3% |

- 切分噪声合并中位 **0.30%**、p90 **0.76%**——30720 个位置的 ER 估计几乎是决定性的。
- 跨周期 0.9–4.6% 的差异**方向一致（全部下降）、随深度增大**，是真实漂移（训练使表示谱收敛），不是估计误差。ER 绝对水平 480–566 / 768 维。

### 2.3 休眠占比稳定性——ReDo 阈值能不能定

**不能直接搬。** 实测各 site"通道均值 / 层内最大通道均值"的分布：

| site 类型 | min | p1 | p50 | ReDo 0.01×max 命中 | ReDo 0.03×max 命中 |
|---|---|---|---|---|---|
| ln1_out / ln2_out（LN 输出） | 0.066–0.66 | 0.076–0.70 | 0.145–0.79 | **0** | **0** |
| attn_out | 0.082–0.24 | 0.094–0.26 | 0.203–0.35 | **0** | **0** |
| mlp_hidden（GELU 后） | 0.037–0.18 | 0.047–0.19 | 0.083–0.33 | **0** | **0** |

ReDo 的 0.01–0.03 阈值来自 RL 大 batch 下 **pre-LN 之前的利用率**；本架构的 LN 把每个输出通道的尺度钉在 ~1（动态范围 min/max ≥ 0.66），GELU 隐层最深的 b6/b7 也只到 min≈0.037——**32 个 site 用 0.01/0.03×max 一个休眠通道都找不到**。

改用**层内分位法**（bottom-k%，两半各自排序取最小 k 个），集合 Jaccard（中位 / 跨周期）：

| 分位 | 60/60 切分 Jaccard 中位 | 跨周期 Jaccard | 同大小随机基线 |
|---|---|---|---|
| bottom-1%（8/768 或 31/3072 通道） | 0.03–0.78（多数 0.14–0.33） | 0.00–0.78 | 0.01 |
| bottom-5% | 0.32–0.45 | 0.26–0.43 | ~0.03 |
| bottom-10% | 0.36–0.54 | 0.28–0.50 | ~0.05 |

bottom-1% 的具体成员在两个半周期之间大半换血（Jaccard ~0.2）——**单周期账本点名单个"最沉睡 1% 通道"接近重新洗牌**；bottom-5–10% 明显可用；LN 输出 site（如 b0.ln1_out，1% Jaccard 0.69/cross 0.78）最稳。

## 3. 实验 2：探测集噪声底（242 块 / 61889 字节全卷）

### 3.1 确定性与 bootstrap 噪声底

- **同一权重连续 evaluate 两次：242 个逐块值逐位一致（max|Δ| = 0.00e+00）**——全卷评估是确定性的，门控残差里没有评估器随机性。
- 初始权重（训练前）：mean NLL = **5.6921**，逐块 std = 0.0569（范围 5.539–5.839，块间差异主要来自内容难度）。
- **bootstrap 1000 次**（对 242 块有放回重抽求均值）：SE = **0.003556**，95% CI **[5.6853, 5.6992]**，即均值的 **0.062%**。参数法 std/√n = 0.00366，两者一致（逐块近独立）。

### 3.2 生产门控的实测：配对差 std/√n 落在什么数量级

9 组完整睡眠周期模拟（3 组数据切片 [logiqa 记录 0:66 / 66:132 / 132:200，45639–49523 字节] × 3 个窗口采样种子 11/22/33；每组从**同一**出生权重起训 120 步——配对设计，把出生差异隔离掉），用**生产 `probe.gate_decision`（K_MARGIN=2.0）**判决：

| 量 | min | 中位 | max |
|---|---|---|---|
| 配对 SE = std(d)/√n（NLL） | 0.00216 | **0.00238** | 0.00281 |
| SE 占均值比 | 0.038% | 0.042% | 0.049% |
| 真实改善 margin = mean_d（NLL） | 0.0496 | 0.0571 | 0.0961 |
| ε = 2·SE（NLL） | 0.0043 | 0.0048 | 0.0056 |
| 逐块 corr(pre, post) | 0.689 | ~0.77 | 0.815 |

- **9/9 通过**，P(bootstrap mean_d ≤ 0) = 0.000、P(≤ ε) = 0.000——判决带内没有任何翻转风险。
- **配对的价值实测**：非配对 SE（√(var(old)/n+var(new)/n)）是配对 SE 的 **1.8–2.3 倍（中位 2.09）**。逐块配对把新旧权重共有的"这一块内容难"的波动消掉约一半（SE 降 ~52%），残差 SE（0.0024）才是判决的真实分辨率。bootstrap 与参数法逐组一致（差 <4%）。
- 对照玩具模型粗测（SE≈0.0012）：57M 真身体 242 块的配对 SE ≈ **0.0024**，同数量级、约 2 倍——旧外推偏乐观 2 倍，但结论不变。

### 3.3 δ 候选值的关系判读

| 判据 | 结果 |
|---|---|
| SE < δ/3（δ=1% = 0.0569 NLL） | 0.0024 < 0.0190，**满足（余量 ~24 倍）** |
| SE < δ/3（δ=2% = 0.1138 NLL） | **满足（余量 ~48 倍）** |
| SE 与 δ 同量级？ | 否——SE 是均值的 0.04%，δ 是 1–2%，差 24–48 倍 |
| 结论 | **门控可用，无需更大探测集、无需更多步数**；连 ε=2·SE（0.084%）都远低于任何合理的手术容差 |

### 3.4 种子敏感性——"真实改善 vs 噪声"对比基线

- 同一切片、不同窗口种子：margin 在 **0.050 / 0.094 / 0.085**（slice 1）间波动——种间真实差异（cross-seed 配对差）|mean| 达 **0.002–0.043 NLL**，其配对 SE 0.0017–0.0023。即：**种子运气造成的真实结果差异（±0.02 NLL 量级）比门控 SE 大一个数量级**。门控判"是否变好"从不出错（所有 run 的 margin 都 ≥ 10×SE），但"这周期比那周期学得多 35%"完全可能是窗口采样的运气。
- 逐块最大差异达 0.10–0.14 NLL——改善在块间高度不均匀，均值差掩盖了分布。

## 4. 对 M4 的三条具体建议

**建议一（阈值）：生长/凋零判决带按本报告噪声实测设置，且 Taylor 一律用 |g×x|。**
单周期（120 步）账本的通道级变化判决：变化量 = 漂移(信号) ± 两个 120 步估计之差(噪声 ≈ 3.1% 相对)。建议：**判决阈值 ≥ 2×噪声 ≈ 6% 相对变化**（对 p90 尾部通道留到 ≥13%）；有效秩无需阈值带（噪声 0.3%）。休眠判定**弃用 ReDo 0.01–0.03 固定比例**（实测 0 命中），改**层内分位法 bottom-5% 起步**（Jaccard 0.32–0.45）且**连续 ≥2 个周期落在 bottom-k 才动手**——把 ~0.4 的单周期集合稳定性复利成跨周期确认；bottom-1% 名单不得直接作为手术对象。

**建议二（平滑）：双时间尺度 EMA，tag 快 / stable 慢，stable 必须跨周期累计。**
数据依据：半衰期扫描显示 60 步内 h=15 相对 h=∞ 仅增加 1–2 个百分点的波动（近 iid，lag1≈0.12–0.17）——**tag EMA 半衰期 15–30 步**足够响应且不炸噪声；**stable EMA 半衰期 ≥ 240 步（2 个周期）**，iid 外推把通道噪声从 ~3%（60 步）压到 ~1.5%、4 周期（122880 位置）到 ~1.1%。特别注意：Taylor 有 **trend=−0.27 的系统性衰减**（跨周期 35%），stable 口径的 Taylor 若直接长半衰期 EMA，会把全局衰减误判成"全员凋零"——**stable-Taylor 必须做周期间重整**（除以当期层内中位数，或只用周期间相对变化率），stable-激活则可直接长 EMA。

**建议三（样本量与判决粒度）：探测集不动，账本侧把 Taylor 的"身份"职责降级或升粒度。**
242 块/61889 字节对门控绰绰有余（SE=δ 的 1/24–1/48），不要为门控加大探测集。账本侧：单周期 30720 位置对**激活范数与有效秩**足够（噪声 2–4% / 0.3%）；对**逐通道 Taylor** 只够当快信号（p90 25%）。若 M4 需要 Taylor 的稳态身份（例如"重要性衰减到基准 x% 才准凋零"），两条路二选一：a) **判决粒度从通道升到通道组/注意力头**（组内取均值/求和，噪声 ∝ 1/√组宽，3072 维 MLP 按 128 通道分组可把 p90 从 25% 压到 ~5%）；b) **跨周期累计**（4 周期 Taylor 噪声 9.5%→~4.8%，但受建议二的重整约束）。按现数据，推荐 a+b 组合且把单周期 margin 仅当通过/否决信号、不当收益度量（§3.4）。

## 6. 局限性声明（必读）

1. **随机初始化模型 vs 训练后模型**：全部测量在随机初始化身体上做（B 路线出生态，测的是估计量的统计性质而非模型质量）。出生孪生设置（student=teacher）下 KD 锚定最强，240 步 CE 几乎持平（5.5467→5.5714），因此测得的**漂移分量偏保守**——部署中段各半球带着多轮学习成果，权重每周期移动的幅度与方向分布会不同；激活通道的动态范围（休眠判断的原料）也会随训练演化（随机初始化下通道利用率天然比训练后均匀）。数字应视为**量级与结构**（噪声 ∝ 1/√n、LN 输出无休眠信号、Taylor 符号口径不可用、漂移主导 Taylor）可信，**绝对百分比为先验**。
2. **logiqa 子集 vs 全源语料**：训练流与切片只用了 logiqa 前 200 条（14.2 万字节），而生产喂食是 7 源混合（cmath/gsm8k/distil/coig/synlogic/metamath/logiqa，2.36GB+）。不同源的字节统计（中文比例、模板重复度、难度分布）会改变逐块 NLL 的离散度（直接影响配对 SE）与激活通道分布（直接影响休眠占比）。探测集噪声底用的是真探测集（242 块）故 SE 的量级可信；账本侧数字在混合语料下需复核。
3. **先验定标，在线自校准**：这些数是 M4 动工前的先验，不是终局真理。M4 上线后，vitals 账本必须保留在线自校准通道——至少持续在线估计：a) 每通道估计量的滚动波动（本报告的 4.4%/9.5% 应被运行时数字取代）；b) 门控配对 SE 的滚动分布（0.0024 会随模型收敛而变——模型越训练 CE 梯度越小，周期内权重移动变小，SE 与 margin 都会缩）；c) 休眠分位阈值的经验命中率。律固定，值自成——本报告给出的是这些反馈量的初值与量纲。
4. 其余测量选择的影响：Gram/每步 svdvals 均按"每步去均值"口径（去 DC），ER 绝对值与不去中心化的口径不可直接互比；窗口采样按生产 `rng.randrange(0, N-blk-1)` 有放回抽窗，未去重（与生产一致）；exp2 的出生孪生设置对应生产"首次周期/作废回滚后再睡"的场景，中段周期（sleeping≠teacher）的 margin 分布可能更宽。
