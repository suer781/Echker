## 0. 结论先行

**核心判断：海豚现有的"变异重放 + KD 蒸馏 + 体检门控 + 反刍做梦 + 恒温器生长"不是科幻类比，而是与持续学习（Continual Learning）与睡眠启发机器学习（Sleep-inspired ML）文献高度同构的一整套工程方案。** 每条机制都能在文献里找到对应物；真正缺的不是"机制是否成立"，而是两件事：

1. **缺显式课程/优先级调度**：现有 L4 带通门控 ≈ RHO-LOSS 的简化版，但没有把"难度 × 价值 × 未学"做成随模型能力动态调整的课程调度器（本次总问题的落地点）。
2. **缺"生成式做梦"的互补增强**：现有反刍做梦只检索真实旧经验（L5 安全），文献表明生成式重放（Deep Generative Replay）可以更强但**不稳定**（MyGO 已撤稿），且纯自生成数据训练会导致模型坍缩（Shumailov 2024 Nature）。**结论：生成式重放不是"真实数据变异重放"的替代，而是互补的做梦增强，且必须继续锚定真实数据（L5 不能破）。**

逐条对应（详见 §1 映射表）：

| 海豚机制 | 文献同构物 | 证据级 |
|---|---|---|
| 变异重放（L6，`sleep.py varied_replay`） | Experience Replay（DQN）+ 重放增强（Text-Mixup、Saliency-Augmented Memory Completion）+ Hindsight 式改写目标（HER） | 同构（功能级） |
| KD 蒸馏锚定真实数据（L5） | Dark Experience Replay（DER）、iCaRL、van de Ven 生成重放+蒸馏、LLM 睡眠论文的 Knowledge Seeding | **同构（机制级）** |
| 体检门控（L8） | MLOps 金丝雀发布（无生物对应，项目已标注）；睡眠文献中的 wake 后评估（SIESTA） | 装饰（工程独立） |
| 反刍做梦（`feed.py ruminate` + `memory.py dream`） | Generative Replay / Dream2Learn / World Models·Dreamer 的想象回滚 / ReST / SPIN 自我对弈 | 类比（做梦用真实数据变体，文献用生成数据） |
| 恒温器生长（M4-T，`life.py`） | RigL / SET / GradMax 的结构可塑性 + Butz & van Ooyen 设定点控制 + 睡眠期突触修剪（Yang 2017） | 同构（信号级）+ 类比（执行窗口） |
| 带通价值门控（L4） | RHO-LOSS（可学×值得学×未学）、PER（TD-error 优先采样） | 同构（选择逻辑） |

**最值得读的三篇文献**（与海豚设计几乎逐点对应的三篇）：
- **Dark Experience Replay**（arXiv:2004.07211）：NeurIPS 2020。就是"重放真实经验 + 对过去 logits 做蒸馏"，在通用持续学习基准上打败大量复杂方法——海豚 L5+L6 的设计与它同构，且海豚更保守（蒸馏锚定同一批真实数据）。
- **RigL**（arXiv:1911.11134）：ICML 2020。每隔 ΔT=100 步，按权重幅值剪枝、按梯度幅值生长连接，α=0.3 余弦衰减到训练 3/4 停止——海豚恒温器的"ghost 梯度选址 + 成熟刹车"与之一脉相承。
- **Language Models Need Sleep**（arXiv:2606.03979，2026）：明确把 LLM 训练分成"Memory Consolidation（小模型知识蒸馏进大模型）"+"Dreaming（RL 自生成课程数据自练）"两阶段——这是海豚"睡脑离线训练 + 反刍做梦"在 LLM 上的直接翻版。

## 2. 重点评估

### 2a) 生成式重放/伪复述 vs 当前"真实数据变异重放"：更优？互补？

**结论：不是更优替代，而是互补增强。当前真实数据变异重放 + KD 蒸馏是文献中验证最强的稳定基线；生成式重放可以作为"做梦增强"，但绝不能成为教材主源。**

证据链：

1. **重放真实数据 + 蒸馏就是强基线**。DER（arXiv:2004.07211）只用"存储样本 + 对过去 logits 做 MSE"，就在 General Continual Learning 上打败大量复杂方法（包括很多生成式方法）。iCaRL 也是"示例重放 + 蒸馏 + NME 分类器"的经典强基线。海豚的 L5+L6+L7 组合**已经站在 DER 之上**，而且更严格（蒸馏锚定同一批真实数据）。

2. **生成式重放有效但有前提、且不稳定**。
   - 支持面：Deep Generative Replay（arXiv:1705.08690）在任务增量 MNIST 上证明生成旧任务伪样本可以防遗忘；van de Ven & Tolias（arXiv:1809.10635）证明"生成重放+软目标蒸馏"在三种持续学习场景都最优。
   - 反例面：MyGO（arXiv:2508.21296，一个完整的 wake-sleep 生成式离线巩固框架）**已由作者撤稿**，原因是生成重放组件在高维数据上不稳定。这直接说明"用生成模型做梦"在工程上脆。

3. **纯自生成数据训练 = 模型坍缩**。Shumailov 等（arXiv:2305.17493，Nature 2024）证明在模型自生成内容上训练会导致分布尾部消失、不可逆退化。这是 L5（禁止用模型自生成内容当教材）的硬证据。即使有奖励过滤的 ReST/SPIN 自我对弈，也需要外部奖励/人类数据锚定。

4. **对海豚的具体建议**：
   - **主路径保持现状**：反刍做梦 = 从记忆库检索真实经验 → 变异重放（换序/拼接/遮盖重填）→ 双损失训练。这是 L5 安全且文献验证的"重放+蒸馏"强基线。
   - **生成式做梦只做输入侧增强、不做教材**：当模型具备生成能力后，L6 的第四算子"改写（复述）"可以由睡脑自己生成改写版本作为训练输入，但**硬标签/软标签仍锚定原始真实经验**（即"输入变体、标签真实"）。这与现有遮盖重填同构（`sleep.py:43` 已明确"不从模型自生成内容取材"——但那是禁止把生成内容当经验入库；输入侧变体不违反 L5，因为标签仍是真实数据）。实施时需要在 `sleep.py` 增加一个"复述生成→输入侧变异"算子，并保留 L5 断言。
   - **不要引入"生成旧任务伪样本作为独立训练语料"**（DGR 式），因为 a) 我们的数据是字节流语言，生成模型质量远达不到图像 GAN 的水平；b) MyGO 已演示该路线的高维不稳定；c) L5 是律，不能破。
   - 成本评估：生成式做梦 = 中成本（需要模型自生成管线 + 质检），收益 = 边际（变异重放已覆盖大部分）。**建议推迟到 L6 第四算子成熟后再说**。

### 2b) 睡眠期结构生长/修剪：频率与幅度有无文献支持？

**结论：文献支持"低频、小幅、早停"的结构手术。海豚恒温器的"每周期判决 + 死区/冷却/五重阻尼 + 成熟刹车"在方向上完全正确；幅度 λ_g=0.04 与 RigL α=0.3 相比偏保守（合理）；频率上"每周期都可能判决"偏密，但已被死区/冷却/守卫限频，且连续设定点控制（Butz）本身就是批处理决策——不需要改成"每 K 周期"。**

具体证据：

1. **频率：拓扑更新应该是"低频事件"**。
   - RigL 的调度是 **ΔT=100 步**更新一次拓扑，且更新到训练 3/4 处停止（T_end=25k for ImageNet / 75k for CIFAR-10），α=0.3 余弦衰减到 0（ar5iv 全文：https://ar5iv.labs.arxiv.org/html/1911.11134 ）。也就是说结构更新不是每一步都做，而是"每隔一段、越到后期越少"。
   - SET 是周期性（每若干 epoch）剪/长连接，固定稀疏度（arXiv:1707.04780）。
   - 睡眠式结构/权重调整的频率：Krishnan 2019 是"每个任务训练后睡一觉"（arXiv:1908.02240）；"Not Just After One" 是**连续学 2+ 个任务后再睡**（arXiv:2606.08447）——频率可以比"每任务"更低；睡眠式稳态正则的睡眠占比 10–20% 最优（arXiv:2601.08447）。
   - 对照海豚：`life.run_cycle` 每个睡眠周期末尾做一次恒温器判决（研究报告_自适应原理.md:447）。由于睡眠周期本身由"睡眠压力积累"触发（不是每一步），**结构手术已经是"低频事件"**，与 RigL 的 ΔT=100 语义一致。恒温器内部的死区（H_SHRINK=0.06）、冷却（GROW_COOLDOWN）、五重阻尼（stable-EMA/确认窗/限频/不对称增益/自适应）进一步保证不会连续开刀。研究报告_自适应原理.md:16 已明确"阶梯的真正风险不是步子大，是太频繁"——这个判断与文献一致。
   - **建议**：不要改成"每 K 周期强制手术"或"固定手术周期"（日历信号是项目明令禁止的，研究报告_自适应原理.md §1.6 反对周期计数器）。当前"每周期测量、带内不动、带外才动"就是 RigL"低频+余弦衰减"的设定点版本。

2. **幅度：小幅、乘性、梯度定向**。
   - RigL 每次更新 30% 的连接（α=0.3 起步），但这是**连接级**（sparse topology 上的一小部分边），不是神经元级。
   - GradMax 每次只加**少量神经元**（论文在 ResNet 上每次加几个通道），用 SVD 梯度匹配初始化。
   - Butz & van Ooyen 的生长曲线是**乘性生长律**（每步生长率 ν，正比于钙偏差），海豚 δ=λ_g·W·e 是直接移植（研究报告_自适应原理.md:402）。λ_g=0.04（4% 乘性）在 Transformer 上属于很保守的步长；文献没有给 Transformer 的标定值，但"乘性 + 小幅 + 负反馈"是机制级正确的。
   - **成熟刹车有文献支持**：RigL 在训练 3/4 处停止拓扑更新；海豚成熟刹车用 margin 分位下台阶调低 λ_g_eff（但永不归零，研究报告_自适应原理.md:363-366）。"永不停学但减速"比 RigL 的硬停止更符合终身学习设定。
   - **自适应幅度有文献支持**：Turrigiano 突触缩放是乘性且自适应的（https://www.nature.com/articles/29328 ）；海豚 λ_g 随体检成败 ×0.5/×1.1 是合理的反馈回路。

3. **风险提示（文献给出的反面教训）**：
   - **结构手术过于频繁会破坏优化器状态**：研究报告_自适应原理.md:16 已指出每次手术重置受影响参数优化器状态 + LR 重启窗。RigL 选择 ΔT=100 也是为了避免频繁改动拓扑导致训练不稳定。海豚的 SURGERY_LR_WINDOW（手术后 LR 重启窗）正是对这一风险的工程化。
   - **生长必须要有方向信号**：SET 的随机生长弱于 RigL 的梯度生长（研究报告_自适应原理.md:188 已引对比）。海豚 ghost 增益作为方向门槛是对的。
   - **收缩比生长更危险**：MyGO 撤稿是生成组件问题，与结构无关；但"睡太多/剪太狠"在文献中有病理化先例（Butz 2014 ηA≠ηD 错配导致癫痫样误连，研究报告_自适应原理.md:65 已引）。海豚"生长难、收缩相对易"的不对称增益设计（研究报告_自适应原理.md:363）正是为了避免这种病态。

## 3. 对海豚的具体落地建议（含接口与风险）

### 3.1 课程调度器（本次调查总问题的落地点之一）

文献依据：RHO-LOSS（arXiv:2206.07137）选样本的三因子 = **可学（reducible loss）× 值得学（loss 高）× 未学（当前模型还不熟）**。海豚 L4 带通（惊讶度中位数 ± IQR）已是"未学×值得学"的简化实现；要升级为显式课程调度，可加第三因子"可学性"：用滚动窗口的 loss 降幅（reducible loss）替代纯惊讶度。

- 接口建议：在 `experience.py` 的评分函数中，把带通权值从"惊讶度 × (1+奖励) × 去重惩罚"扩展为 `w = learnability(e) × worth(e) × novelty(e)`，其中 learnability 用该经验近几轮重放的 loss 降幅估计（与 `dolphin/adapt.py` 的滚动统计共用）。
- 改动文件：`dolphin/experience.py`（评分）、`dolphin/adapt.py`（新增 learnability 统计）、`tests/test_conformance.py`（新增断言）。
- 风险：learnability 估计需要该经验被重放多次才有统计；冷启动阶段数据不足时退化为现有带通。**建议作为可选开关**，先用 band-pass 兜底。

### 3.2 反刍做梦：保持真实数据锚定，可加"输入侧生成变异"

- 文献结论（§2a）：生成式重放与真实数据重放互补，不替代。建议维持 `feed.py ruminate` + `memory.py dream` 现状；待模型生成能力成熟后，在 `sleep.py varied_replay` 增加第四算子"复述"——由睡脑对某条真实经验生成改写版作为训练输入，但**硬/软标签仍锚定原始真实字节**（L5 断言必须覆盖"输入变体"场景）。
- 风险：模型自生成输入可能引入系统性偏差（Model Collapse 的轻度形态）。缓解：生成变体只占训练 batch 的少数（如 ≤20%），且体检门控（L8）会把退化模型拦在门外。

### 3.3 恒温器：频率/幅度保持现状，补充两点文献级加固

- **保持**：每周期测量、设定点带内不动、带外小幅乘性生长、成熟刹车、不对称增益。这些都是 RigL/Butz/Turrigiano 的正向结论。
- **加固 A（对应 RigL "3/4 处停止更新"）**：成熟刹车目前用 margin 分位下台阶，`λ_g_eff` 降低但不归零。可增加一个"长期无结构动作验证"日志（不是新开关），观察成熟期手术频率是否自然趋近于零，作为 RigL"早停"语义的自校准证据。
- **加固 B（对应"低频"）**：研究报告已把"太频繁"判定为主要风险，当前死区+冷却+确认窗已限频。建议在 `life.py` 报告字段中增加 `last_surgery_cycle`、`surgery_gap_hist`，供查房观察实际手术间隔分布，验证是否落在"每数十周期一次"的量级。
- 改动文件：`dolphin/life.py`（仅加日志字段）、`ward.py`（展示）。**不动触发链**（L11 红线：不干预时机/位置/幅度）。

### 3.4 显式"睡眠频率"的文献量级参考（不是强制改）

睡眠式稳态正则的最优睡眠占比 10–20%（arXiv:2601.08447）；"Not Just After One" 支持连续学多个任务再睡。海豚现在的睡眠触发=睡眠压力积累（惊讶度积分），阈值带自校准（太频繁调高、太稀调低）。**不需要改成固定占比**——但可以在阈值反馈里把 10–20% 作为先验参考（例如：若某个长期窗口内训练步数 vs 睡眠周期数远超 5:1 或低于 2:1 的极端情况，检查压力阈值是否漂移）。

## 5. 一句话收尾

海豚不是"模仿睡眠"的玩具——它的每个部件都能在持续学习/睡眠机器学习文献里找到**机制级**对应物（DER、RigL、CLS、睡眠-清醒两阶段），且它用"L5 锚定真实数据"躲开了文献中最新的两个坑（模型坍缩、生成重放不稳定）。下一步最值得投入的是把 L4 带通升级成 RHO-LOSS 式三因子课程调度，而不是替换现有重放/蒸馏主线。
